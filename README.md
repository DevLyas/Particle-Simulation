
# Particle Simulation

A simple particle simulation made with Raylib and C.

Use the arrow keys to add or delete particles.

## Preview

![](/preview.gif)

## Dependencies

- C compiler (gcc, clang, ...)
- Raylib
- Cmake

## Getting Started

- create the build directory and enter it  
`mkdir build && cd build`

- run cmake  
`cmake ..`

- build the simulation  
`make`

- run the simulation  
`./main`
